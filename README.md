# Alumni Management & Tracking System

This project is a web-based **Alumni Management and Tracking System** developed as part of the Web Programming course at Istanbul University.

## Technologies

The project is built using the following technologies:

* **Backend:** FastAPI with Python
* **Database:** PostgreSQL
* **Database ORM:** SQLAlchemy
* **Deployment & Environment:** Docker and Docker Compose

## Project Structure

The application is designed using a **layered software architecture**. Different responsibilities such as API endpoints, application logic, and database operations are organized into separate layers.

The project structure may be expanded and improved during the semester according to the topics covered in the course and newly introduced requirements.

## Getting Started

To run the application in a Docker environment, use the following command:

```bash
docker compose up
```

Docker Compose will start the required services defined for the project.

## Development Process

The system will be developed step by step throughout the semester. New features and improvements will be added as the project progresses, and the development process will be documented through regular Git commits.
